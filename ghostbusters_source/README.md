# Ghostbusters — A True Story? v1.2

Independent review build for later Green Tank integration.

## Core rules
- No hero narrative.
- AL is one ordinary person on a learning journey.
- Evidence, lived experience, interpretation and unknowns are distinguished.
- Fear and ego are treated as protective systems that can misinterpret, not villains.
- Some dangers are real; the project asks what was observed versus what imagination added.
- Improvement matters, but perfection is not a condition for human worth.
- No single medium controls the explanation.
- Repository links allow visitors to inspect the public work.
- Project 67 remains directly reachable.
